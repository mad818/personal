# Second Brain House Rules

## Pipeline

- `0-raw/` is immutable intake.
- `1-desk/` is scratch and review space.
- `2-atoms/` is approved permanent knowledge, one claim per file.
- `3-threads/` is approved synthesis built from atoms.
- `sources/` is an immutable original-source archive.
- `briefings/` is the operator-facing shift and audit record.

## Prime directive

Every durable atom must trace to a real file in `0-raw/` or `sources/`. No source, no note. Never fill a gap with likely-sounding model knowledge.

## Working rules

1. Search existing atoms before proposing a new one.
2. Keep one claim per atom.
3. Link related atoms when real relationships exist. If a new vault cannot supply two links yet, mark the atom `[ORPHAN]` for audit instead of inventing links.
4. Add a `[FRICTION]` block when evidence pressures an existing atom. Do not resolve the conflict automatically.
5. Never overwrite or delete. Use approved retirement or supersession with provenance.
6. Automatic work stops at `1-desk/`. Only explicit human approval promotes permanent notes.
7. Audits report. They do not repair.

## Authority

- Automatic runtime: read immutable intake, write bounded desk proposals, write report-only audits.
- Human-approved promotion: create new atoms, threads, and final briefings without overwriting existing files.
- Ambiguous, destructive, private-to-public, or conflicting action: stop and ask Mario.
