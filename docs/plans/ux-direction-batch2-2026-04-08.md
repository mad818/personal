# UX Direction Batch 2 — HQ mission rail

Date: 2026-04-08
Owner: Codex

## Why this batch

The UX brief calls for a mission-oriented layer over the existing tabs:

- Observe
- Investigate
- Automate
- Archive
- Launch

HQ is the safest first place to implement that because it is already the most operator-facing entry surface and already contains doctrine, posture, and routing context.

## Goals

1. Add a compact mission rail to the HQ prelude.
2. Keep the existing tabs and Strategium deck intact.
3. Make the first action clearer without turning HQ into a generic dashboard.
4. Keep the rail task-first and low-text.

## Constraints

- Do not remove tabs or existing HQ actions.
- Do not change provider/runtime behavior.
- Keep free-first/local-first defaults unchanged.
- Keep the live site running while verifying.

## Expected outcome

- HQ becomes a clearer “start here” surface.
- Users can begin from intent instead of hunting across tabs.
- The new layer enhances the current IA instead of replacing it.
