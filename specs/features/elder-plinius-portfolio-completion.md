# Elder Plinius portfolio completion

## Intent

Complete the remaining `elder-plinius` source-intake debt with a current, repository-by-repository inventory and adapt the one newly verified product-safe pattern through an existing Nexus surface.

- Public profile: `https://github.com/elder-plinius?tab=repositories`

- NATURALIS FUTURA:
  - `https://github.com/elder-plinius/NATURALIS-FUTURA`

## Product slice

1. Record all 45 repositories in one machine-checkable inventory with primary-evidence notes and an explicit disposition.
2. Remove the indefinite `remaining-portfolio` source-parity placeholder.
3. Add NATURALIS FUTURA to the existing Company Map as a reference for explainable AI-risk briefings:
   - state the technical threat;
   - use one memorable cross-domain analogy only as an explanation aid;
   - pair it with concrete mitigations and verification evidence;
   - label uncertainty and never treat the analogy as proof.
4. Place the source only in Research & Knowledge and Legal & Trust.

## Benefits

- Operators can understand and remember abstract AI risks without losing the technical threat or its controls.
- Every public repository has an auditable outcome, so a future review can identify exactly what changed.
- Useful ideas stay inside existing Nexus routing instead of creating a second app or provider authority.

## Exclusions

- No upstream runtime, source code, text, threat-creature names, game mechanics, map, art, or assets.
- No jailbreak, prompt-exfiltration, offensive-security, model-safeguard removal, adversarial image, hardware-control, or autonomous code-generation runtime.
- No direct provider client, credential, telemetry, database, account system, token, payment, or dependency.
- No medical claims, altered-state visualizer, media player, community platform, Discord bot, 3D-printer control, or cryptocurrency feature.
- No phone/PWA or private RPG path.
