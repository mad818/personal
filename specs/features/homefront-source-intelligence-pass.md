# HOMEFRONT-SOURCE-INTELLIGENCE-PASS

## Intent

Carry the latest external resource batch into the Homefront vision as source-intelligence discipline: useful outside projects become mapped patterns, not copied code, public claims, or hidden runtime dependencies.

## Scope

- Add a public landing section that explains how Homefront ingests external ideas: scan, map, gate, and remember.
- Add a public active-intake queue so the supplied links show what is active, staged, or guarded instead of sitting as a flat list.
- Add a compact authenticated shell rail for non-HQ surfaces so operators see the same source-intake posture inside the product.
- Add a native `/resources?view=sources` workbench lane so source intake becomes an operator workflow instead of landing/shell copy.
- Consolidate source-intelligence lanes, queue, guardrails, and shell intake posture in one shared registry.
- Update the external-links mapping docs with the new GitHub/X batch and the safe disposition for each group.
- Keep the RPG/private creative lane separate from the public Homefront story.

## Guardrails

- No offensive automation or arbitrary third-party scanning.
- No vendored external repo code.
- No unverified asset, security, or agent-runtime dependency.
- No public Aether/RPG positioning.
- X links stay staged until individually reviewed.

- Public `/` includes `landing-source-active-queue` with current active/staged source lanes.
