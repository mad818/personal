# Financial Research Source Closure

## Outcome

Adapt the safe research patterns from TradingAgents and Dexter into ALPHA as a
bounded, evidence-separated council without autonomous market action or
fabricated financial certainty.

## Product behavior

1. A user-triggered thesis gathers bounded symbol-matched public news and
   primary-source SEC filing evidence.
2. The SEC route resolves a valid ticker, returns filing metadata, and extracts
   recent XBRL revenue, income, assets, liabilities, and diluted EPS facts with
   period context.
3. Fundamentals, technical, sentiment, and risk lenses return typed handoffs
   before one balanced synthesis.
4. Every result separates observed facts, bull and bear cases, risks, valuation
   context, and verify-next work.
5. Conviction measures evidence completeness only. It is never presented as
   return probability or investment performance.
6. The deterministic Position Sizer remains manual and shows fixed-risk
   exposure, stop distance, risk/reward, loss at stop, and Kelly reference.
7. Nexus does not place orders, connect brokers, scrape earnings transcripts,
   recursively expand research tools, or backtest model prose as a strategy.

## Verification

- `npm run financial-research:source:check`
- `npm run source:parity:closure:check`
- `npm run type-check`
- `npm run lint`

## Benefits

- Primary SEC facts replace guessed fundamentals.
- Bull and bear cases make disagreement visible before synthesis.
- Missing evidence remains unavailable instead of silently neutral.
- Research stays useful without becoming an autonomous trading system.
