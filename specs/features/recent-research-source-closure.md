# Recent Research Source Closure

## Outcome

Adapt the safe, useful recent-research patterns from Last30Days into Nexus's
existing protected evidence lanes without importing its account scraping,
installer, or direct-provider runtime.

## Product behavior

1. Fast-moving Feynman research emits deterministic 30-day query windows.
2. Initial and refinement searches execute in bounded parallel groups and
   normalize results into one evidence ledger.
3. Writer, Verifier, Reviewer, and the integrity passport produce one cited
   brief with visible gaps and degraded receipts.
4. Nexus exposes a narrower keyless public baseline through Hacker News,
   Polymarket, public papers, public repository intelligence, news, and web
   evidence.
5. Source-local engagement can remain contextual data, but Nexus does not merge
   incomparable popularity and money signals into one truth score.
6. Nexus does not scrape browser sessions, bulk comments, transcripts, or
   person profiles and does not install external assistant or MCP runtimes.

## Verification

- `npm run recent-research:source:check`
- `npm run feynman:progressive:check`
- `npm run source:parity:check`
- `npm run type-check`

## Benefits

- Time-sensitive research has an explicit recent window.
- Parallel collection remains bounded and source-audited.
- Existing free public sources stay useful without pooled social credentials.
- Popularity cannot silently masquerade as factual confidence.
