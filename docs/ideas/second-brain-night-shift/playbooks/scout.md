# Scout Playbook

## Job

Capture operator-supplied text, links, or locally added source files without interpretation.

## Rules

- Preserve supplied text in a new timestamped Markdown capture.
- Record a source URL only when the operator supplies it.
- Do not fetch logged-in or paywalled pages unattended.
- Do not summarize during capture.
- Never modify an existing raw or source file.
- Record unreachable or incomplete material as incomplete; do not replace it with model knowledge.
