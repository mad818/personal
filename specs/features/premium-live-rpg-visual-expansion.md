# Premium Live + RPG Visual Expansion

## Intent

Carry the premium live Homefront visual language forward while starting the replacement lane for older Aether Reliquary imagery.

## Scope

- Add one compact live-vision strip to the authenticated non-HQ shell threshold.
- Keep `/hq` excluded from Homefront product positioning.
- Create a machine-readable RPG visual replacement contract for retired/rejected prologue sheets.
- Surface replacement status inside existing `/hq` drawers instead of making a new route.
- Add validation so rejected/reference-only sheets cannot become approved fallback art.

## Guardrails

- No public sales copy.
- No paid or unreviewed asset dependency.
- No promotion of rejected Bellroot glyph/vector sheets.
- No movement of RPG World out of `/hq` in this pass.
- No generated placeholder runtime art without prompt/provenance records.

## Verification

- `npm run arpg:visual-replacements:check`
- `npm run type-check`
- `npm run verify`
- `npm run build`
