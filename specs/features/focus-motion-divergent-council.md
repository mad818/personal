# Focus, Motion, and Divergent Council Assimilation

## Objective

Assimilate the useful behavior from `emilkowalski/skills`, `ayghri/i-have-adhd`, and `UditAkhourii/adhd` into existing Nexus design and HQ assistant surfaces without installing external plugins, adding dependencies, making diagnosis claims, or creating an expensive default agent path.

## Nexus surfaces

- `docs/NEXUS_TASTE_CONTRACT.md` and a project-owned motion decision contract remain the design authority.
- The existing HQ `Direct` persona becomes the opt-in action-first reading mode.
- The existing HQ `Council` remains the only parallel assistant surface and gains an explicit capped divergent strategy.
- Skills Company Map and source-parity records expose provenance, benefits, and exclusions.

## Motion contract

- A reusable deterministic decision function evaluates interaction frequency, purpose, surface type, and input mode before approving motion.
- Keyboard and high-frequency actions stay instant; decorative motion is rejected on data-dense surfaces; approved motion receives a bounded duration budget.
- The focused gate rejects high-confidence active-source anti-patterns: `transition-all`, inline broad `transition: var(--t)`, exact `ease-in`, and `scale(0)` entrances.
- Reduced-motion coverage, property-specific transitions, current Nexus tokens, and the existing cinematic identity remain intact.

## Focus output contract

- Direct mode leads with the answer or next action, numbers multi-step work, suppresses tangents, keeps lists bounded, makes completed work visible, and ends with at most one concrete next action when work remains.
- Errors stay matter-of-fact. Time estimates may be concrete only when grounded in real evidence; Nexus must not invent timing.
- The behavior is an operator-selected output preference, not a diagnosis, demographic inference, global hidden instruction, or new persisted personal-data field.

## Divergent Council contract

- Divergence activates only when Council is already enabled and the prompt explicitly asks for `/diverge`, `diverge:`, `divergent council`, `brainstorm wide`, or `ideate widely`.
- Nexus reuses exactly three existing parallel Council calls under isolated evidence-auditor, inversion, and zero-budget frames. Branches do not see each other.
- The existing manual Merge action performs the critic pass through one pinned JANSKY call: cluster ideas, score novelty/viability/fit, flag traps, choose a shortlist, identify the non-obvious viable option, and name a first step.
- Adopt and Merge drafts pin JANSKY so leaving Council enabled cannot accidentally fan out another three calls.
- No auto-trigger on generic questions, ten-call loop, new provider, direct SDK, hidden chain-of-thought exposure, autonomous execution, or background persistence.

## Source and licensing boundary

- All three sources are MIT, but Nexus independently encodes project-owned rules and short frame descriptions rather than vendoring upstream skill files or runtime code.
- Each source receives a scoped repo analysis and exhaustive source-parity matrix with every capability marked adapted or excluded.

## Acceptance evidence

- Runtime fixtures prove motion decisions, strict explicit divergence triggers, exactly three isolated framed members, deterministic ordering, frame-preserving results, and one-call pinned merge/adopt drafts.
- Static checks prove Direct-mode output rules, Council usage disclosure, property-specific transitions, Company Map provenance, repo-analysis boundaries, complete parity matrices, package wiring, and zero phone/PWA/RPG changed paths.
- TypeScript, zero-warning lint, formatting, Company Map, source parity, design/motion gates, publication/security checks, one canonical verification run, and one production build pass.
