# UX Direction Batch 7 — Scheduler + VAULT Intro Compaction

Date: 2026-04-08
Owner: Codex

## Why this batch

The action flow is getting stronger, which means some guidance blocks can now get lighter.

The next low-risk density wins are:

1. Scheduler template/governance areas, where several notes repeat the same posture in slightly different words.
2. VAULT memory-spine intro, where stacked callouts can now collapse into a more concise operator-facing explanation.

## Goal

Reduce repeated explanatory text while keeping:

- the safety boundary obvious
- the action path obvious
- the operator aware of restricted/local-only posture

## Approach

1. Scheduler:
   - keep one strong expandable note for templates
   - replace repeated review-only prose with concise chips and titles
   - compress governance explanation into one shorter note plus action row
2. VAULT memory spine:
   - replace stacked introductory callouts with one concise note
   - keep counts and restricted posture visible as compact badges

## Constraints

- Improve, do not remove.
- No new large panels.
- No loss of safety posture.
- Keep free-first/local-first unchanged.

## Success criteria

- Scheduler and VAULT intros scan faster.
- Repeated prose decreases without reducing trust.
- Verification and live route checks remain green.
