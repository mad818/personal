# David Ondrej Skill Closure

## Outcome

Reconcile the current `davidondrej/skills` catalog against reachable Nexus behavior and close every source row without importing a second agent runtime, paid DeepAPI dependency, global host mutation, or unbounded infrastructure authority.

## Source truth

- Source: `https://github.com/davidondrej/skills`

- License: MIT
- Current top-level families: agent orchestration, skill authoring, research/web, thinking/docs, and operations/setup, plus shell-safety hooks

## Product contract

1. Existing Nexus behavior is the implementation when it already provides the full useful outcome:
   - typed specialist delegation and handoffs;
   - iterative execution state with interruption/resume;
   - canonical repository handoff;
   - project-owned engineering skill lifecycle;
   - bounded browser, web, URL-read, deep-research, API, prompt, learning, scheduling, and document workflows;
   - provider setup, secure-link inspection, security audit, and platform-independent tool isolation.
2. Every implemented or adapted row names reachable proof and is checked by one focused validator.
3. Source-specific wrappers are not duplicated when the project-native path is already stronger or more portable.
4. Capabilities are excluded only where the original outcome requires autonomous scheduling, terminal-multiplexer control, global host writes, commerce, paid transcript fetching, host power mutation, a database target Nexus does not own, or unbounded VPS mutation.
5. Publication, connectors, credentials, external writes, and infrastructure changes remain separately operator-authorized.
