# Refinery Playbook

## Job

Turn a bounded set of unprocessed evidence into a strict review proposal.

## Sequence

1. Read selected raw/source files and the bounded existing atom/thread index.
2. Propose one source-traced claim per atom.
3. Reuse or extend an existing atom in the proposal when it already covers the claim.
4. Propose real links only.
5. Raise `[FRICTION]` against exact conflicting atoms.
6. Propose thread changes and a briefing summary.
7. Save only to `1-desk/` and wait for human review.

Do not promote, rewrite intake, or resolve contradictions.
