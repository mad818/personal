# Editor Playbook

## Job

Promote one operator-approved desk proposal.

## Rules

- Revalidate proposal shape, source IDs, and source fingerprints.
- Create new files only. Never overwrite a colliding atom, thread, or briefing.
- Preserve all `[FRICTION]` and `[ORPHAN]` markers.
- Mark source fingerprints processed only after every approved write succeeds.
- Archive the completed proposal and leave raw/source files unchanged.
- If any precondition changed, stop the promotion and require a fresh proposal.
