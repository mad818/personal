# Landing Story Depth Pass

## Goal

Make the public Homefront landing feel current and substantial without turning it into a sales page. The added space should explain the point of the project: local-first command intelligence, protected operator access, useful memory, agent roles, and proof-minded work.

## Scope

- Deepen the existing premium single-page landing rather than replacing the visual system.
- Add more project-specific content to the public page: system architecture, agent bench, operator workflow, and proof boundaries.
- Keep `/hq` and RPG World private and out of public positioning.
- Keep copy honest to the current build stage: no invented customers, no subscription language, no deployment promises beyond current project posture.

## Acceptance

- Public `/` still renders the premium Homefront landing and access threshold.
- Landing regression coverage checks the new story-depth sections.
- The page contains no public RPG product positioning.
- `npm run type-check`, `npm run verify`, `npm run build`, and live route proof pass or blockers are recorded.
