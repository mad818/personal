# CodeWhale + OBLITERATUS Native Assimilation

## Purpose

Assimilate CodeWhale's useful runtime-governance and continuity patterns into
the existing Nexus agent runtime, and adapt OBLITERATUS only as passive,
local-only model safety evaluation.

## CodeWhale Lane

- Define one machine-checkable authority order used by the active agent prompt.
- Protect Nexus invariants for free/local operation, approval-gated mutation,
  provider routing, evidence-first completion, and verification before done.
- Record a structured continuity receipt for every Nexus agent-run artifact.
- Represent interrupted and stale running work honestly instead of treating it
  as completed.
- Select a bounded runtime harness posture without adding a second agent
  runtime, terminal UI, updater, package installer, or hosted relay.

## OBLITERATUS Lane

- Extend the existing local Model Lab with passive safety evaluation manifests.
- Compare refusal consistency, policy robustness, coherence, harmless
  helpfulness, stability, leakage pressure, and usefulness.
- Keep evaluation derived and local-only. No model provider call is required.
- Record explicit guardrails in every new run: no weight modification, no
  steering-vector application, no safeguard removal, no remote telemetry, no
  model upload, and no remote code execution.
- Preserve existing Model Lab history and the existing Skills workbench.

## Source Boundary

- CodeWhale is an idea and behavior source. Nexus does not vendor or launch its
  Rust runtime.
- OBLITERATUS is an analysis vocabulary source only. Nexus does not vendor its
  AGPL code or reproduce its guardrail-removal purpose.
- Both sources require exhaustive parity matrices with every capability marked
  implemented, adapted, or explicitly excluded.

## Acceptance

- The active Nexus agent prompt includes the authority and evidence contract.
- New agent-run artifacts carry structured continuity receipts.
- Stale running lifecycle state reconciles to interrupted.
- Model Lab creates validated passive-safety runs with immutable prohibited
  capability declarations.
- Focused runtime and static assimilation checks pass.
- `npm run source:parity:check`, `npm run type-check`, and `npm run verify`
  pass.
