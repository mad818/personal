## Decision summary

- Remove from the published root: `agent-workspace`, `start-nexus.ps1`, and the
  old root `CODEOWNERS` location.
- Substantively refresh the previously RPG-labelled active folders: `public`,
  `tests`, and `desktop`.
- Retain compatibility and history only where current runtime, validation,
  recovery, or audit evidence proves an owner.
- Leave older but valid configuration untouched when the only complaint is its
  displayed commit age. The release does not manufacture churn to change labels.
