# Warp repository analysis

Warp's useful Nexus fit is a behavior pattern, not its terminal runtime.

The live source differs from the old matrix:

- default branch: `master`;
- UI framework crates: MIT;
- remaining source: AGPL-3.0;
- current product: a broad agentic development environment.

The bounded adaptation is a clean-room palette inside Nexus's existing global
CommandBar:

- fixed local route registry;
- deterministic fuzzy search;
- visible command descriptions and selected preview;
- keyboard open, movement, activation, close, and focus return;
- no query-driven execution or network/model use.

Benefits:

- existing workplanes become discoverable;
- keyboard navigation becomes faster;
- preview reduces accidental navigation;
- search remains local and private;
- no terminal, shell, dependency, second route, or copied Warp code enters
  Nexus.
