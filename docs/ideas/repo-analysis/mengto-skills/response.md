# MengTo/Skills analysis

`MengTo/Skills` is a strong fit as a procedure source, not as a vendored runtime.

The useful integration is a project-owned atlas covering every feasible non-game capability:

- 101 searchable non-game operating procedures;
- complete inputs, ordered steps, guardrails, acceptance checks, and prerequisites;
- the existing Nexus Skill Library as the visual discovery surface;
- read-only list and resolve tools for agent use;
- explicit connector, host, and dependency requirements;
- 20 game capabilities excluded from active Nexus behavior.

Benefits:

- repeatable design and builder workflows instead of one-off prompting;
- better proof, accessibility, performance, originality, and cleanup checks;
- honest external-tool posture;
- no bulk install, copied demos, new route, or restored game runtime.

The complete source-to-Nexus decision ledger is `docs/ideas/source-parity/mengto-skills.json`.
