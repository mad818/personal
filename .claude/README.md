# Claude compatibility layer

This directory is retained for tools that still discover Claude-style agents,
commands, hooks, rules, or skills. It is a compatibility layer, not a second
source of project authority.

Current work starts with `AGENTS.md`, `SECOND_BRAIN.md`,
`docs/AGENT_HANDOFF.md`, `docs/SYSTEM_STATE.md`, and `tasks/todo.md`. The
security hook and skill files here remain tracked because current Nexus
validators and compatibility discovery still exercise them. They cannot
override verified repository state or the root instructions.
